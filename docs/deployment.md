# 미리보기와 배포

## 현재 상태

- 공개 URL: https://mzljieun.github.io/wedding-invitation/
- GitHub Pages는 현재 `main`의 `/(root)`를 배포합니다.
- `develop`에서 새 React 화면을 개발합니다.

## 권장 방식: 공개 주소와 테스트 주소 분리

React 프로젝트 안에 준비 화면과 청첩장 화면을 별도 컴포넌트로 둡니다. 배포마다 공개할 화면을 명시합니다. 구체적인 빌드 설정은 배포 단계에서 결정합니다.

| 용도 | 화면 | 주소 |
| --- | --- | --- |
| 하객용 | 공개 전 준비 화면, 공개일 이후 청첩장 | 기존 GitHub Pages 주소 |
| 작업 중 확인 | 개발 중인 청첩장 | 로컬, 필요하면 별도 테스트 URL |

별도 테스트 배포는 하객용 화면을 바꾸지 않고 휴대폰에서 확인할 수 있습니다. 실제 사진이나 연락처가 포함되면 접근 제한이 있는 미리보기를 우선합니다. URL을 알기 어렵게 만드는 것만으로는 비공개가 되지 않습니다.

## 대안: 같은 주소에 잠깐 테스트 배포

사용자가 원할 때 테스트 버전을 배포하고, 확인이 끝나면 검증된 준비 버전을 다시 배포합니다. 테스트 중에는 하객도 청첩장을 볼 수 있고, 다시 배포해도 이미 열어 둔 탭이나 공유 미리보기가 즉시 바뀌지는 않을 수 있습니다. 같은 주소로 테스트해야 한다면 임시 데이터로 먼저 확인합니다.

React 전환 후에는 Vite로 빌드한 정적 결과물을 배포할 예정입니다. 기존 공지 페이지를 React로 재현하고 로컬 검증을 마치기 전에는 Pages 설정을 바꾸지 않습니다. 테스트 서비스·주소와 실제 배포 설정은 아직 정하지 않았습니다.
