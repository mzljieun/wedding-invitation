# 기능 요구사항

한 페이지를 스크롤하는 모바일 청첩장을 만듭니다. 준비 페이지와 청첩장 화면은 별도로 관리합니다. 아래는 구현 예정 범위입니다.

| 영역 | 완료 기준 |
| --- | --- |
| 준비 페이지 | 기존 공지 문구와 디자인을 React로 재현 |
| 표지·초대 | 흑백 표지 사진, 이름, 예식 정보와 초대 문구 표시 |
| 예식 일정 | 달력에 예식일 강조, 한국 시간 기준 D-day, 일정 저장 |
| 사진 | 좌우 스와이프, 사진 확대, 이전·다음·닫기 |
| 오시는 길 | 주소 복사, 지도 표시, 네이버지도·TMAP·카카오내비 연결과 대체 링크, 교통·주차 정보 |
| 마음 전하기 | 감사 문구, 신랑측·신부측 펼치기, 계좌 복사와 완료 안내. 이름·전화는 공개할 항목만 반영 |
| 방명록 | 작성·조회, 관리자 숨김·삭제, CSV/JSON 내보내기. 외부 저장 서비스와 공개 정책은 미정 |
| 마무리 | 감사 인사, 청첩장 링크 공유 |

참석 응답과 배경음악은 제안 단계입니다. React 초기 설정 단계에서는 준비 페이지만 다루고, 방명록과 지도 서비스 연동은 후속 단계에서 별도 설계합니다.
