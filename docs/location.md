# 오시는 길

공식 약도와 주소 안내 구현 · 모바일 지도 앱 검증 전

## 출처와 확인한 정보

- [더화이트베일 공식 위치 안내](https://thewhiteveil.co.kr/Location): 주소, 대중교통·주차 안내, 네이버지도 링크, 청첩장용 약도 다운로드
- 사용자 제공 파일 `location (1).pdf`: 1페이지 약도. 이미지로 렌더링해 예식장, 지하철 출구, 맞은편 주차타워 표시를 확인했습니다. 원본은 저장소 밖에 둡니다.

| 항목 | 안내 |
| --- | --- |
| 예식장 | 더 화이트 베일 4층 W Hall · 서울특별시 서초구 서초중앙로 14 |
| 지하철 | 3호선 남부터미널역 4번 출구, 도보 약 2분 (예식장 안내 기준) |
| 주차 | 예식장 맞은편 전용 주차타워 · 서울특별시 서초구 서초중앙로2길 10 |

버스 안내는 공식 페이지에 5300-1, 첨부 PDF에 6016이 기재되어 있어 일부가 다릅니다. 노선은 공개 전에 다시 확인하며, 주차 요금·무료 시간은 확인 전까지 표기하지 않습니다.

## 화면 설계

1. 예식장·홀과 주소를 먼저 표시하고, **예식장 주소 복사**를 제공합니다.
2. 공식 약도에서 지도 부분만 읽기 좋은 이미지로 준비하고, 누르면 확대할 수 있도록 합니다. PDF 전체를 화면 폭에 맞춰 넣으면 교통 안내 글씨가 작아지므로, 핵심 안내는 별도 텍스트로 표시합니다. 원본은 공식 안내의 약도 다운로드 링크로 확인할 수 있게 합니다.
3. **네이버지도**와 **예식장 공식 안내**를 버튼으로 제공합니다. 주차장 주소는 예식장 주소와 분리하고 차량 이용자가 따로 복사할 수 있게 합니다.
4. 지도 임베드, TMAP·카카오내비 연결은 오시는 길 구현 단계에서 검토합니다. 앱이 열리지 않을 때도 주소 복사와 웹 지도 링크를 이용할 수 있게 합니다.

## 완료 기준

- 좁은 화면에서도 예식장과 주차장 주소를 구분해서 읽고 각각 복사할 수 있습니다.
- 약도를 확대해 출구와 주차타워 표시를 확인할 수 있습니다.
- 실제 휴대폰에서 지도 버튼이 올바른 목적지를 여는지 확인합니다. 현재는 공식 페이지에 실린 링크 주소만 확인했습니다.

## 구현 및 검증

`WeddingLocation.jsx`를 갤러리 아래에 연결하고, PDF에서 지도 부분만 `venue-map.png`로 추출했습니다. 로컬 브라우저에서 약도 확대·닫기와 예식장·주차장 주소 복사 성공을 확인했습니다. 지도 임베드와 TMAP·카카오내비 연결은 이번에 구현하지 않았습니다.

본문은 예식장 정보 → 약도 이미지 보기 → 지도·길찾기 → 지하철·주차 안내 순서로 구성합니다. 약도는 버튼을 누르면 어두운 오버레이 중앙에 전체 이미지가 표시됩니다. 오른쪽 위 닫기 버튼, Escape 또는 바깥 배경으로 닫을 수 있습니다. 로컬 브라우저에서 버튼, 약도 전체 표시와 배경 클릭 닫기를 확인했습니다.

참고 화면에 맞춰 예식장 전화 링크와 본문 위치 안내도를 추가했습니다. 본문 안내도는 공식 PDF의 주요 지점을 간략화한 SVG(축척 없음)이며 누르면 네이버지도 장소로 연결됩니다. 상세 공식 약도는 별도 버튼으로 표시합니다. 버스는 두 자료에서 일치하는 4319, 461, 641만 표기했습니다. 로컬에서 본문 표시와 약도 열기·닫기를 확인했습니다.

## 네이버지도와 내비게이션 설정

- 주소 복사 버튼은 예식장·주차장 모두 제거했습니다. 기존 주소 텍스트는 유지합니다.
- [네이버클라우드 Maps Application](https://guide.ncloud-docs.com/docs/maps-app/)에서 Web Dynamic Map을 활성화하고 웹 서비스 URL에 실제 호스트(공개: `https://mzljieun.github.io`, 로컬: `http://127.0.0.1`)를 등록합니다. 포트나 저장소 하위 경로를 넣지 않습니다.
- `.env.example`을 참고해 `.env.local`에 브라우저용 Client ID(`VITE_NAVER_MAP_CLIENT_ID`)와 확인된 예식장 WGS84 위·경도를 넣고 개발 서버를 재시작합니다. Client Secret이나 서버용 키는 사용하지 않습니다. 키나 좌표가 없거나 지도 타일 로딩에 실패하면 위치 안내도와 네이버지도 링크가 유지됩니다.
- 티맵·카카오내비에서 실제 예식장 목적지를 공유한 HTTPS 링크를 얻으면 각각 `VITE_TMAP_DESTINATION_URL`, `VITE_KAKAO_NAVI_DESTINATION_URL`에 넣고 모바일에서 테스트합니다. 공유 링크가 목적지 전달을 지원하는지는 앱에서 확인해야 합니다. 카카오내비 직접 길안내 SDK 방식을 선택하면 [별도의 JavaScript 키와 SDK 도메인 등록](https://developers.kakao.com/docs/ko/kakaonavi/js)이 필요합니다. 링크 미설정 시 카드에 연결 준비 중을 표시합니다.
- 현재 청첩장 화면은 개발 서버에서 미리보기로만 제공됩니다. 로컬에서 기본 안내도, 세 카드, 약도 열기·닫기와 주소 복사 버튼 제거를 확인했습니다. 키가 설정된 실제 지도와 앱 전환은 검증하지 않았습니다.

## 교통 안내 보완

공식 위치 페이지를 기준으로 지선 4319, 간선 461·641, 직행·공항 5300-1·8501의 번호와 주요 경유지를 표기합니다. PDF와 다른 노선은 공식 웹 안내를 우선하며, 실제 운행 정보는 예식 전에 다시 확인합니다. 3호선은 주황색, 지선은 초록색, 간선은 파란색, 직행·공항은 적색 배지로 표시합니다. 승용차 안내와 주차장 도로명·지번 주소를 추가했으며, 로컬 브라우저에서 배치와 문구를 확인했습니다.
