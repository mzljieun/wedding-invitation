# 작업 순서와 결정 기록

| 단계 | 작업 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| 0 | 기존 개발 초안 정리와 설계 재구성 | 준비 페이지 기준 복원, 예식 정보·요구사항 보존 | 완료 |
| 1 | npm 기반 React + Vite 기본 설정 | 설치, 개발 서버, 프로덕션 빌드 확인 | 완료 |
| 2 | 준비 페이지 React 전환 | 기존 문구와 디자인을 좁은 브라우저 화면에서 비교 | 완료 |
| 3 | 청첩장 화면을 영역별 구현 | 표지부터 한 영역씩 구현·검증 | 진행 중: 마음 전하실 곳까지 구현 |
| 4 | 미리보기와 공개 배포 | 미리보기 검증 후 기존 주소에 공개, 준비 화면 복귀 방법 확인 | 예정 |

- **npm 선택:** 이전 pnpm 사용은 작업 환경에 내장되어 있었기 때문입니다. 이 프로젝트는 npm으로 충분하며, 사용자가 익히고 쓰려는 도구로 통일합니다. 설치 후 `package-lock.json`을 관리합니다.
- **새 출발:** 이전 React 전환 초안은 작업 폴더에서 제거합니다. 예식 정보와 기능 요구사항은 문서로 보존합니다.
- **테스트 배포:** 별도 미리보기 주소를 우선 검토합니다. 실제 서비스와 접근 범위는 배포 단계에서 결정합니다.

검증 기록:

- 0단계: 화면 파일을 main의 준비 페이지와 비교했습니다.
- 1단계: npm으로 의존성을 설치하고 `package-lock.json`을 생성했습니다. `npm run build`로 `dist/`를 생성했고, Vite 개발 서버의 `/wedding-invitation/` 응답에서 준비 페이지 문구를 확인했습니다. 이 단계에서는 기존 HTML·CSS를 유지했으므로 React 화면의 브라우저 비교는 2단계에서 진행합니다.
- 2단계: 준비 화면을 `src/ComingSoon.jsx`로 옮기고, `src/main.jsx`에서 React로 렌더링합니다. 기존 CSS를 유지했습니다. 빌드 후 `/wedding-invitation/`에서 제목과 문구를 확인했고, 같은 브라우저 창 크기에서 전환 전후 캡처가 일치했습니다. 실제 모바일 기기와 공개 배포는 검증 범위에 포함하지 않았습니다.
- 3-1단계(표지): `src/Cover.jsx`와 전용 CSS에 흑백 가로 사진, 이름, 예식 일시와 장소를 배치했습니다. 원본은 보존하고 긴 변 1,800px의 EXIF 없는 복사본을 사용합니다. 로컬 브라우저에서 기본 준비 화면과 좁은 창의 표지 미리보기를 확인했습니다. 배포용 빌드가 통과했고 표지 사진이 결과물에 포함되지 않았습니다. 실제 휴대폰과 공개 배포는 확인하지 않았습니다. 다음 범위는 초대 문구입니다.
- 3-2단계(초대 문구): `src/Invitation.jsx`와 전용 CSS에 인사말 초안과 두 사람의 서명을 추가했습니다. `WeddingPreview.jsx`에서 표지 아래에 연결했고, 좁은 브라우저 창에서 문구와 배치를 확인했습니다. 배포용 빌드는 통과했으며 미리보기는 포함되지 않습니다. 문구 확정, 달력, 오시는 길은 이번 범위에 포함하지 않았습니다. 다음 범위는 예식 일정입니다.
- 3-3단계(예식 일정): 초대 문구 아래에 3월 달력, 서울 날짜 기준 D-day, `.ics` 저장 링크를 추가했습니다. 좁은 브라우저 창에서 토요일 6일 강조와 D-day, 링크를 확인했고 파일의 시작 시각과 장소를 검사했습니다. 예식 종료 시각은 미확정이라 넣지 않았습니다. 배포용 빌드는 통과했고, 휴대폰 캘린더 앱에서 실제 가져오기는 확인하지 않았습니다. 다음 범위는 사진 갤러리입니다.
- 3-3단계 보완(카운트다운 시계): 달력 아래에 예식 시작 시각(2027-03-06 13:00 KST)까지 남은 일·시·분·초를 표시합니다. 매초 현재 시각으로 다시 계산하고 시작 후에는 0으로 표시합니다. D-day 문구는 서울 날짜 차이를 표시합니다. 좁은 로컬 브라우저 창에서 배치와 초 갱신을 확인했고 배포용 빌드는 통과했습니다. 예식 시작 이후 동작은 브라우저에서 재현하지 않았습니다.
- 3-4단계(사진 갤러리): 예식 일정 아래에 사진 3장의 가로 스크롤과 확대 보기를 추가했습니다. 원본을 보존하고 미리보기는 긴 변 800px, 확대용은 최대 1,800px로 준비했습니다. 로컬 브라우저에서 확대, 다음 사진, Escape 닫기, 원래 버튼으로 포커스 복귀를 확인했습니다. 배포 빌드에 갤러리 사진이 포함되지 않는 것을 확인했고, 실제 휴대폰의 터치 스와이프는 아직 확인하지 않았습니다. 다음 범위는 오시는 길입니다.
- 3-4단계 보완: 갤러리를 한 장씩 보이는 슬라이더로 바꾸고, 목록과 확대 화면의 이동 화살표를 사진 영역의 양옆 세로 중앙에 배치했습니다. 로컬 브라우저에서 화살표 배치와 슬라이더 좌우 이동을 확인했습니다.
- 3-4단계 보완: 사진 확대를 브라우저 표시 영역을 채우는 어두운 오버레이로 바꿨습니다. 사진은 비율을 유지하고, 닫기와 이동은 아이콘 버튼으로 표시합니다. 로컬 브라우저에서 사진 클릭 시 유지, 바깥 배경 클릭 시 닫기를 확인했습니다. 브라우저 주소창을 숨기는 전체화면은 사용하지 않으며, 실제 모바일 기기에서는 확인하지 않았습니다.
- 3-4단계 보완: 가운데 카드와 인접 카드 일부, 현재 번호를 표시하는 슬라이더로 변경했습니다. 터치·트랙패드는 기본 가로 스크롤을 사용하고, 마우스 드래그는 클릭과 구분합니다. 가로 표지는 전체 구도를 유지하고, 세로 카드는 확대 시 고해상도 사진의 전체 구도를 보여줍니다. 로컬 브라우저에서 마우스 드래그와 확대를 확인했으며, 실제 휴대폰 터치는 확인하지 않았습니다.
- 3-5단계(오시는 길): 공식 약도 확대, 예식장·주차장 주소 복사, 지하철 안내, 네이버지도와 공식 안내 링크를 추가했습니다. 로컬 브라우저에서 확대·닫기와 두 주소 복사를 확인했습니다. 배포 빌드는 통과했으며 휴대폰 지도 앱 전환은 검증하지 않았습니다. 다음 범위는 마음 전하실 곳입니다.
- 3-6단계(마음 전하실 곳): 오시는 길 아래에 감사 문구와 양가 펼침 영역을 추가했습니다. 공개에 동의한 계좌가 등록되면 예금주·은행·계좌번호와 복사 버튼을 표시합니다. 로컬 브라우저에서 양쪽 열기와 한쪽만 닫기를 확인했고 빌드도 통과했습니다. 실제 계좌와 연락처는 추가하지 않았고 복사 동작은 미검증입니다. 다음 범위는 방명록 설계입니다.
- 3-6단계 보완: 신부측에 송금 금지 표시가 붙은 미리보기용 예시 계좌를 추가했습니다. 로컬 브라우저에서 예시 표시와 복사 성공 안내를 확인했습니다. 공개 전 예시 계좌를 제거하거나 동의받은 정보로 교체합니다.
- 3-6단계 보완: 계좌 복사는 아이콘으로 표시하고, 복사 성공 안내는 버튼 위에 1초간 띄웁니다. 로컬 브라우저에서 표시와 자동 닫힘을 확인했습니다.
